Musette share test

Works out whether iOS will offer Ride with GPS as a destination for a shared GPX, and if so which file type makes it appear.

How to run this:
  1. Open this page on the iPhone that has the Ride with GPS app installed.
  2. Tap each Share button in turn.
  3. For each one, note whether Ride with GPS appears in the app row. Check behind the More (···) button at the end of the row too — RWGPS's own docs say it can hide there.
  4. Dismiss the sheet and move to the next case.
